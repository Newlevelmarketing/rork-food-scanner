# Prompt 05 — Resume Project

Use this in ChatGPT or Claude Code when returning to a project after a break.

> `/brain-resume` runs this same routine.

```txt
Read the project context and help me resume work.

Start with:
1. `CLAUDE.md` or `AGENTS.md`
2. `context/project-overview.md`
3. `context/strategy-context.md`
4. `context/architecture.md`
5. `context/execution-standards.md`
6. `context/ai-workflow-rules.md`
7. `context/ui-brand-context.md`
8. `context/progress-tracker.md`
9. `context/decision-log.md`
10. Any relevant file inside `context/feature-specs/`

Then give me:
1. Current project status
2. What has already been completed
3. What is in progress
4. Open questions or blockers
5. The next 3 recommended units of work
6. The safest next prompt to send to Claude Code

Do not implement anything unless I explicitly ask.
```
